# 墨メモ クローズドテスト実施手順

## 公開申請までの必須条件
Google Playの新しい個人用デベロッパーアカウントでは、12人以上が直近14日間連続でクローズドテストにオプトインしている必要があります。条件達成後に製品版へのアクセスを申請し、テスターの参加状況、フィードバック、改善内容、公開準備について回答します。14日経過だけで自動承認されるわけではありません。
公式資料: https://support.google.com/googleplay/android-developer/answer/14151465?hl=ja

## 募集と参加
- 推奨募集人数は15〜20人。12人を下回る離脱に備えるための運用上の余裕で、Googleの追加要件ではありません。
- 家族、友人、同僚、開発者コミュニティなどから、実際にAndroid端末で使って感想を返せる人を募集します。
- Google Playで使うGoogleアカウントのメールアドレスを、開発者へ非公開で伝えてもらいます。公開のGitHub Issueには個人のメールアドレスを書かないでください。
- 開発者がConsoleのテスターリストに登録した後、参加者は同じGoogleアカウントで参加リンクを開き、参加を確定し、Google Playからインストールします。
- 参加リンク（現在はテスト未公開のため利用不可）: https://play.google.com/apps/testing/app.sumimemo.offline
- メールアドレスを登録するだけでは参加成立ではありません。参加者本人のオプトインが必要です。
- 14日以上、テスト参加を解除しないよう依頼します。継続参加人数と期間はConsoleで確認します。

## テスト内容
実際の個人情報や機密情報を使わず、試し書きのメモで確認してください。
1. 日本語タイトルと複数行の本文を作成し、保存して開き直す。
2. メモを変更し、アプリを離れて戻り、内容が保存されているか確認する。
3. タイトル・本文で検索し、一致しない検索も試す。
4. メモを固定し、一覧上部に表示されるか確認する。
5. ごみ箱への移動、キャンセル、復元を確認する。
6. 編集中の画面回転と、アプリ終了後の再起動を試す。
7. キーボード表示や大きい文字設定で、保存ボタンと本文が扱いやすいか確認する。
8. プライバシー説明と全文リンクを確認する。

## 推奨する14日間の運用
- 参加開始時: オプトインとインストールを確認し、主要機能を一通り試してもらう。
- 前半: 普段のメモ用途で使い、使いにくい点を集める。
- 中盤: 報告を分類して修正し、必要に応じて更新版を配信する。
- 後半: 更新版で改善点を再確認し、未解決の問題と公開判断をまとめる。
これは推奨運用です。Googleが毎日何分の操作を一律に指定しているという意味ではありません。

## フィードバックの記録
宛先: Criotion@proton.me
Google Playの非公開テストフィードバックも利用できます。
次の内容を集めてください: 端末機種、Androidバージョン、アプリバージョン、試した操作、期待した結果、実際の結果、再現手順、改善要望。
個人情報を含む画面や本物のメモ内容は送らないよう案内してください。
記録形式: 日付 / 端末 / 操作 / 問題・感想 / 対応 / 修正版 / 再確認結果。

## 製品版アクセス申請用にまとめる内容
- どのように参加者を集め、何人が継続して参加したか。
- どの機能を使ってもらい、想定する利用方法とどの程度一致したか。
- どのようなフィードバックを、どの窓口で受け取ったか。
- テストの結果どこを改善し、何を再確認したか。
- 公開可能と判断した根拠と、残っている制約。
実施した内容だけを記載し、利用実績・人数・フィードバックを作らないでください。
