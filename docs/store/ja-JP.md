# 墨メモ — Google Play掲載原稿

アプリ名: 墨メモ
言語: 日本語
カテゴリ案: 仕事効率化
料金案: 無料（広告・アプリ内課金なし）
パッケージ: app.sumimemo.offline

## 短い説明
ひらめきを、手元に。通信なしで使えるシンプルなメモ帳。

## 詳しい説明
墨メモは、思いついたことをすぐ書き留められるオフラインのメモアプリです。

・タイトルと本文を自由に編集
・タイトルと本文から検索
・大切なメモを一覧の上部に固定
・削除したメモはごみ箱から復元
・保存ボタン、戻る操作、アプリを離れる際に保存

アカウント登録は不要。広告、アクセス解析、通信機能はありません。
メモはアプリ内の端末ストレージに保存します。

ご注意:
クラウド同期・エクスポート・自動バックアップには対応していません。
アプリのアンインストールやアプリデータの消去でメモは失われます。
暗号化された保管庫ではありません。

## 初回リリースノート
メモの作成・編集・検索・固定、ごみ箱からの復元に対応しました。
